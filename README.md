## 📋 О проекте

Репозиторий содержит лексико-семантическую онтологию традиционных российских духовно-нравственных ценностей и инструменты для автоматизированной оценки ценностно-смысловой согласованности образовательных текстов с использованием методов компьютерной лингвистики.

**Автор:** Шаповалов М.И.  
**Назначение:** Научное исследование, апробация методики

---

## 🎯 Цели исследования

1. **Формирование онтологии** традиционных ценностей на основе триангуляции нормативных, педагогических и лингвистических источников.
2. **Разработка алгоритмов** расчёта трёх ключевых метрик:
   - **ИЦЛП** — Индекс ценностно-лексической плотности
   - **ИКАН** — Индекс культурно-адаптивной нейтральности
   - **ИЦВ** — Индекс ценностной валентности
3. **Апробация методики** на реальных педагогических текстах.
4. **Обеспечение воспроизводимости** результатов через открытый код и данные.

### Способ 1: Через GitHub Codespaces (рекомендуется)

Самый простой способ запустить скрипты без установки Python на компьютер:

1. Нажмите зелёную кнопку **`<> Code`** → вкладка **Codespaces** → **Create codespace on main**.
2. Дождитесь загрузки среды (~30 секунд).
3. Откройте терминал: `Terminal` → `New Terminal`.
